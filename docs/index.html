Recent research

最近研究的主题

围绕一个核心问题展开：高层算子最终如何映射到 GPU 的指令、存储和流水线上？

01

Tensor Core / Data Movement

Blackwell TCGen05 与异步流水

研究 TCGen05 MMA、TMA、TMEM、mbarrier、warp specialization 与 CLC persistent scheduling，拆分 compute-only、copy-only 和真实 mainloop 的性能边界。

  • SM100
  • SM110
  • TMA
  • TMEM
  • NCU
02

Compiler Lowering

PTX → SASS 可审计映射

用最小 PTX kernel、O0/O3 配对编译和双路反汇编，把核心 opcode、操作数布置与编译器发射协议分层归因。

  • PTX ISA
  • ptxas
  • nvdisasm
03

Memory Hierarchy

Shared Memory 与 Swizzle

从地址到 bank 的映射出发，研究 LDS/STS、cp.async、TMA 与 descriptor-driven operand path，区分冲突、广播和 profiler 可观测边界。

  • Bank conflict
  • Swizzle
  • Wavefront
04

Low Precision

NVFP4 量化 GEMM

关注 E2M1 payload、E4M3 block scaling、packed layout、requantization epilogue，以及低精度格式对 GEMM 数据流和吞吐的影响。

  • NVFP4
  • FP8
  • CUTLASS
  • CuTe

About

以证据驱动性能工程

我的工作习惯是先定义可证伪的问题，再构造最小对照实验。性能数字必须同时回答：测量对象是什么、计时边界在哪里、指令是否真的生成、结果是否正确，以及结论不能外推到哪里。

目前希望继续深入 GPU 算子、AI Infra、异构计算和训练/推理系统，把微架构理解连接到真实模型的端到端性能。
