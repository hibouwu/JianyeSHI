研究方向

我在巴黎萨克雷大学学习高性能计算，主要关注 GPU 算子开发、CUDA 性能优化和编译器前端。近期工作围绕 NVIDIA Blackwell / Thor 展开，包括 Tensor Core 计算、异步数据搬运、Shared Memory 布局与低精度 GEMM，以及 PTX 语义和生成指令的验证。

我希望把微架构实验中的观察落实到算子实现中，并用参考结果、性能测量与反汇编解释优化的效果和适用范围。

研究与项目

Blackwell / Thor CUDA 内核优化

CUDA · Tensor Core · TMA / TMEM · 低精度 GEMM

使用 raw CUDA 和 inline PTX 实现 Thor 上的 FP16×FP16→FP32 GEMM，研究 TMA 数据搬运、TCGen05/TMEM、warp 分工与常驻调度，并实现 NVFP4 的 E2M1 数据、E4M3 块缩放和 requantization epilogue。

在归档的 1024³、tc5b 十轮实验中，结果均通过参考对照，平均性能达到 cuBLAS Tensor Core（cublasGemmEx）的 92.7%。该数字对应这一规模与历史参考实现，不代表所有规模或模型端到端性能。

PTX 语义、typed IR 与 PTX → SASS 验证

PTX · LLVM / NVVM · ptxas · nvdisasm

将 PTX 解析、类型与指令语义校验、typed LLVM/NVVM IR 发射分层组织，保留地址空间和指令修饰信息。前端输出与协作后端分开验证。

围绕 B200 归档 206 个最小 PTX 静态用例，包含 205 个合法输入和 1 个规范负例；对照 O0/O3 编译结果、双路反汇编、环境信息与 SHA-256，分析核心 opcode、操作数布置和发射协议。

静态 lowering 说明编译器生成了什么，不单独证明 kernel 的数值正确性。硬件执行、数值对照和性能测量分别记录。

工作方式
