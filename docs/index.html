01

Tensor Core / Data Movement

Blackwell TCGen05 与异步流水

拆 TCGen05 的 MMA、TMA、TMEM、mbarrier 和 warp specialization，分别测 compute-only、copy-only 和真实主循环，看异步流水到底能跑多快。

  • SM100
  • SM110
  • TMA
  • TMEM
  • NCU
02

Compiler Lowering

PTX → SASS 可审计映射

用最小的 PTX kernel，O0 vs O3 对照编译，两边反汇编，看同一个 opcode 到底变成了什么 SASS 指令。

  • PTX ISA
  • ptxas
  • nvdisasm
03

Memory Hierarchy

Shared Memory 与 Swizzle

从地址到 bank 的映射，拆 LDS/STS、cp.async、TMA 的 operand path，弄清楚什么时候是真的 bank conflict。

  • Bank conflict
  • Swizzle
  • Wavefront
04

Low Precision

NVFP4 量化 GEMM

NVFP4 的 E2M1 payload + E4M3 block scaling，看 quant/dequant 走哪条路径，低精度格式对 GEMM 数据流的影响。

  • NVFP4
  • FP8
  • CUTLASS
  • CuTe
